# Koopa Run

A mobile-first browser game where you guide Koopa, a Shiba, past sofa obstacles.

## Play locally

Download or clone this project, then open `index.html` in any modern web browser.

## Upload to GitHub

1. Go to [github.com/new](https://github.com/new) and create an empty repository named `kooparun`.
2. Open the repository, choose **Add file** → **Upload files**.
3. Drag in the files from this project (or extract the provided ZIP first), then choose **Commit changes**.

The game needs no build step, server, account, or external dependencies.
